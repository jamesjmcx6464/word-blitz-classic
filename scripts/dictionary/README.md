# Dictionary sources

`src/data/words.json` is generated by `scripts/build-dictionary.py`. Do not hand-edit it.

    npm run build:dictionary
    npm run verify:dictionary

## Inputs

- `two-letter-allowlist.txt` — the only 2-letter words accepted in play (everyday words, solfège syllables, and OK). Kept in sync with `src/data/twoLetterAllowlist.ts`.
- `three-letter-remove.txt` — rare 3-letter words (wordfreq Zipf < 3.0) dropped after a sanity review.
- `three-letter-keep.txt` — familiar Zipf < 3.0 threes that were kept (BIB, BAA, EWE, EEK, …).
- `blocklist.rot13` — slurs, strong profanity, and secondary sexual-vulgar terms, rot13-encoded so the classroom repo does not contain those spellings in plaintext. Not shipped in the game bundle; words are stripped from `words.json` at build time. Decode with `codecs.decode(text, "rot_13")`.
- `enable-9plus-zipf2.txt` — ENABLE 1 words of length 9+ with wordfreq Zipf ≥ 2.0, minus the blocklist. Vendored so a rebuild does not need wordfreq or a network. There is no upper length limit.
- `additions.txt` — holidays, planets, continents/oceans, Canadian places, modern tech words (no brands), and leftover classroom gaps from the audit.

The 2–8 letter base in `words.json` is the previous ENABLE-family list plus a small supplement, after the removals above.

Runtime `src/data/dictionary.ts` still merges countries, professions, months, and days, and enforces the 2-letter allowlist so splits such as `AU PAIR` cannot re-inject `AU`.

## Ambiguous words left in place

These were reviewed and **kept**, at James's direction:

- Mild / insult-adjacent language: HELL, DAMN, POOP, FART, STUPID, and similar everyday words (CRAP, JERK, SUCK, …).
- Anatomical / science words: PENIS, VAGINA, and related classroom-science terms.
- Identity terms (not slurs): GAY, LESBIAN, QUEER, TRANS, BISEXUAL.
- Animal or ordinary senses that can also get giggles: ASS (donkey), COCK (rooster), and similar.

## Scoring

Score is still `2^length`. JavaScript stores that exactly up to 2^53, which is far longer than any dictionary word (current max is 22 letters). A 15-letter word is worth 32,768 points and will dominate a short timed round. Scoring was left unchanged.
